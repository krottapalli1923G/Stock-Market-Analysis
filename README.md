# 📈 Stock Market Analysis with Machine Learning

This project performs **Stock Market Analysis** and **Stock Price Prediction** using **Yahoo Finance API, Pandas, Matplotlib, and Scikit-Learn**.

---

## 🚀 Features
- **Fetch Historical Stock Prices** (Apple, Google, Tesla)
- **Analyze Stock Trends with Candlestick Charts**
- **Predict Future Stock Prices using Machine Learning**
- **Visualize Price Trends and Volatility**
